# AgentKit SDK Test Commands Analysis
## Principal Engineer & Testing Expert Analysis Report

Based on detailed examination of all package.json files, scripts, vitest configurations, and git hooks in the repository.

---

## 1️⃣ CORRECT COMMANDS TO RUN TESTS

### All Tests Across All Packages
```bash
pnpm test
```
**What it does internally:**
- Executes: `pnpm -r --parallel run test`
- Runs the `test` script in all 8 workspace packages in parallel
- Each package uses its own vitest configuration
- SDK package has special timeout wrapper, others use standard `vitest run`

### Only SDK Package Tests
```bash
cd packages/sdk && pnpm test
```
**What it does internally:**
- Executes: `node scripts/validate-tests.mjs && timeout 120s vitest run || ([ $? -eq 124 ] && echo '✅ Tests completed successfully (exit timeout expected)' && exit 0 || exit $?)`
- First runs test structure validation (validates no prohibited files in src/__tests__)
- Then runs vitest with 120-second timeout wrapper
- Uses special exit code handling for timeout scenarios
- Uses VM threads pool with aggressive cleanup setup

### Only a Single Specific Test File
**From SDK package:**
```bash
cd packages/sdk && npx vitest run __tests__/specific-test.test.ts
```
**From CLI package:**
```bash
cd packages/cli && npx vitest run __tests__/specific-test.test.ts
```
**What it does internally:**
- Bypasses package test scripts and runs vitest directly
- Uses the package's vitest.config.ts configuration
- No timeout wrapper or validation scripts

### Node-Only Tests (Excluding Browser)
```bash
pnpm test:node
```
**What it does internally:**
- Executes: `pnpm -r --parallel --filter='!@agentkit/runtime-web' run test`
- Runs tests in all packages EXCEPT @agentkit/runtime-web
- Excludes browser-specific tests and web worker tests

### Browser-Only Tests
```bash
pnpm test:browser
```
**What it does internally:**
- Executes: `pnpm --filter @agentkit/runtime-web run test`
- Only runs tests in the runtime-web package
- Uses Node.js environment with happy-dom for browser API simulation
- Excludes actual browser tests (those are in `test:browser` script in runtime-web)

## 2️⃣ PNPM vs DIRECT VITEST COMMANDS

### When to Use PNPM Commands:
- **Root level tests**: `pnpm test` - Uses workspace orchestration and package-specific configurations
- **Filtered tests**: `pnpm test:node`, `pnpm test:browser` - Leverages pnpm workspace filtering
- **Integration tests**: `pnpm test:integration` - Runs SDK integration tests specifically
- **Production/CI usage**: PNPM commands include validation scripts and proper setup

### When to Use Direct Vitest Commands:
- **Single test files**: `npx vitest run specific.test.ts` - Bypasses package scripts
- **Watch mode**: `npx vitest` - Direct file watching
- **Debug mode**: `npx vitest --inspect` - Debugging capabilities
- **Custom configurations**: `npx vitest --config custom.config.ts` - Override configs

### Key Differences:
1. **SDK Package**: PNPM includes validation script + timeout wrapper, vitest direct does not
2. **CLI Package**: PNPM includes build step (pretest), vitest direct does not
3. **Runtime-Web**: PNPM uses Node environment, direct vitest could use different config
4. **All packages**: PNPM uses workspace context, vitest uses local context only

## 3️⃣ GIT HOOKS THAT RUN TESTS AUTOMATICALLY

### Pre-commit Hook Configuration:
**File:** `.git/hooks/pre-commit` (installed by `scripts/install-hooks.sh`)
**Actual hook content:**
```bash
#!/bin/bash
# AgentKit SDK pre-commit hook
# Installed by scripts/install-hooks.sh

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "$SCRIPT_DIR/../.." && pwd)"

exec "$REPO_ROOT/scripts/pre-commit.sh"
```

### Commands Run by Pre-commit Hook:
**File:** `scripts/pre-commit.sh`
**Commands executed in order:**
1. `npm run typecheck` - Type checking across all packages
2. `npm run test` - Full test suite (all packages)
3. `npm run build` - Build all packages

### Hook Installation:
**Automatic:** Runs on `pnpm install` via `postinstall` script
**Manual:** `pnpm run install:hooks` or `./scripts/install-hooks.sh`

### To Skip Hook Temporarily:
```bash
git commit --no-verify
```

## SUMMARY

**Primary test command:** `pnpm test` (runs everything)
**Development:** `npx vitest` in specific packages for watch mode
**CI/Production:** Use pnpm commands for full validation and setup
**Git integration:** Pre-commit hook runs full test suite automatically
**Special handling:** SDK package has timeout wrapper due to hanging test issue

The repository uses a sophisticated testing setup with package-specific configurations, resource leak detection, and comprehensive git hook integration for quality assurance.
